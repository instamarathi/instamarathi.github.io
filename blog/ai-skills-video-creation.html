AI Agent Skills म्हणजे काय — आणि Video बनवण्यासाठी कामाचे Skills

Tools & How-To · October 2026

Claude Code किंवा Codex ला "माझ्या bakery साठी 15 second reel बनव" असं सांगितलं, तर तो काहीतरी बनवतो. पण दर वेळी तो शून्यापासून विचार करतो — कोणतं tool, कोणती size, captions कसे, render कसा. त्यामुळे result कधी चांगला, कधी गोंधळलेला.

"Skill" हा प्रश्न सोडवतो. Skill म्हणजे AI agent साठी लिहिलेलं एक तयार instruction पुस्तक. ते install केलं की agent ला ते काम "आधीच शिकलेलं" असतं. या post मध्ये skill म्हणजे काय, non-programmer ने ते कसं वापरायचं, आणि video बनवण्यासाठी आज खरोखर उपलब्ध असलेले skills कोणते — ते बघूया.

Agent Skill म्हणजे काय? (सोप्या भाषेत)

एक skill म्हणजे एक folder. त्यात एक SKILL.md नावाची file असते — त्यात skill चं नाव, एका ओळीत "हा skill कधी वापरायचा" याचं वर्णन, आणि मग step-by-step सूचना. सोबत गरज असेल तर scripts (code), reference notes, templates, fonts वगैरे.

reel-skill/
├── SKILL.md      ← नाव + वर्णन + सूचना (हे compulsory)
├── scripts/      ← agent चालवू शकेल असा code (optional)
├── references/   ← जास्तीची माहिती (optional)
└── assets/       ← templates, fonts, images (optional)

Agent हे कसं वापरतो? सुरुवातीला तो फक्त सगळ्या skills ची नावं आणि वर्णनं वाचतो. तुम्ही विचारलेलं काम एखाद्या skill च्या वर्णनाशी जुळलं, की तेव्हाच तो पूर्ण SKILL.md उघडतो आणि त्याप्रमाणे काम करतो. म्हणून 20-30 skills install असले तरी agent गोंधळत नाही.

हे format Anthropic ने बनवलं आणि नंतर open standard म्हणून खुलं केलं (agentskills.io). आज Claude (claude.ai app आणि Claude Code), OpenAI चा Codex, Cursor, GitHub Copilot, Gemini CLI यांसारखे अनेक agents हेच format वाचतात. म्हणजे एकदा skill शिकलात की तो वेगवेगळ्या agents मध्ये चालतो.

एका वाक्यात: Prompt म्हणजे एकदा दिलेली सूचना. Skill म्हणजे agent कडे कायम ठेवलेलं, तपासलेलं "कसं करायचं" पुस्तक — तुम्ही साधं बोललात तरी तो ते पुस्तक उघडून काम करतो.

Non-programmer ने skill कसा वापरायचा?

तुम्हाला code लिहायचा नाही. फक्त तीन गोष्टी:

  1. Agent निवडा: Video skills साठी सहसा Claude Code किंवा Codex लागतो, कारण ते तुमच्या laptop वर commands चालवून video render करतात. Claude Code साठी Claude Pro (साधारण $20/महिना, October 2026) लागतो; Codex ChatGPT plans मध्ये येतो (Plus साधारण $20/महिना).
  2. Skill install करा: बहुतेक skills एका command ने install होतात. उदा. npx skills add remotion-dev/skills. हे command agent ला सांगूनही चालवून घेता येतं — "हा skill install कर" असं लिहा.
  3. साध्या भाषेत मागा: "माझ्या bakery साठी 9:16 reel बनव" — एवढंच. Agent योग्य skill आपोआप उचलतो. हवं तर नावाने बोलवा: Claude Code मध्ये /remotion-create, Codex मध्ये $skill-name.

claude.ai (web/app) मध्येही skills वापरता येतात — Free plan सकट. Settings मध्ये "Code execution / Create and edit files" चालू करा, मग Customize → Skills मध्ये skill चा ZIP upload करा. पण video render करायला जड software (Node, FFmpeg, Chrome) लागतं, म्हणून video साठी laptop वरचा Claude Code किंवा Codex जास्त सोयीचा.

Skills कुठे मिळतात?

  • Official repos: github.com/anthropics/skills (Anthropic चे — documents, design, GIF वगैरे), remotion-dev/skills, heygen-com/hyperframes.
  • skills.sh: Vercel चं directory. Install संख्येनुसार leaderboard, आणि npx skills add owner/repo हा CLI इथूनच येतो.
  • Claude Code plugin marketplace: /plugin marketplace add anthropics/skills सारख्या command ने पूर्ण संच जोडता येतो.
  • GitHub search: "manim skill", "ffmpeg skill" शोधा — पण इथे कोणीही काहीही टाकू शकतो, म्हणून खालचा warning नक्की वाचा.
Skill म्हणजे तुमच्या laptop वर चालणारा code:
  • Skill मधले scripts agent तुमच्या machine वर चालवतो. चुकीचा skill files delete करू शकतो किंवा तुमचा data बाहेर पाठवू शकतो. Anthropic च्या help page वरही हेच लिहिलं आहे — फक्त trusted sources कडूनच install करा.
  • Install करण्याआधी SKILL.md उघडून वाचा. "हा URL ला data पाठव", "ही key कुठे paste कर" असं काही विचित्र दिसलं तर थांबा. समजत नसेल तर agent ला विचारा: "हा skill काय काय करतो ते मराठीत सांग, काही धोकादायक आहे का?"
  • GitHub stars जास्त म्हणजे safe असं नाही. Official company repo (Remotion, HeyGen, Anthropic) ला प्राधान्य द्या.
  • खर्च: Skill बहुतेक free असतो, पण agent चा subscription (साधारण $20/महिना) लागतो. काही skills ElevenLabs, HeyGen सारख्या paid API keys मागतात. आणि budget laptop वर render ला वेळ लागतो — 15 second reel ला काही मिनिटं, मोठ्या video ला जास्त.

Video बनवण्यासाठी कामाचे Skills

खालचे सगळे skills आज (October 2026) GitHub वर उपलब्ध आहेत (repos तपासून ही list बनवली आहे). प्रत्येकासाठी — काय करतो, reel साठी उदाहरण prompt, आणि कोणासाठी योग्य.

1. Remotion Skills (official)

Remotion हे React code ने video बनवण्याचं tool आहे. त्यांच्या official remotion-dev/skills repo मध्ये 12 skills आहेत: नवीन video बनवणं (remotion-create), preview (remotion-studio), render (remotion-render), captions (remotion-captions — Whisper ने laptop वरच transcribe करतो, GPU लागतो), map animations (remotion-maps) वगैरे. सगळ्यांचा router म्हणजे remotion-best-practices.

  • Install: npx skills add remotion-dev/skills
  • Prompt: "Remotion वापरून 1080x1920 चा 10 second reel बनव: 'नवीन batch सुरू — 1 November पासून' हा मराठी text मोठ्या font मध्ये slide होऊन यावा, background orange gradient."
  • कोणासाठी: एकाच design चे 50 variations (प्रत्येक product, प्रत्येक offer) बनवायचे असतील तर. Licence: individuals आणि 3 employees पर्यंतच्या companies ना commercial use free; मोठ्या companies ला paid company licence.

Remotion आणि Manim मध्ये code ने video कसा बनतो याची सविस्तर माहिती Code ने Video — Remotion आणि Manim या post मध्ये आहे.

2. HyperFrames Skills (HeyGen)

HyperFrames हे HeyGen चं open-source (Apache 2.0) framework — HTML/CSS animation चा MP4 video बनवतो. Skills install केल्यावर /hyperframes हा मुख्य skill तुमची request ओळखून योग्य workflow निवडतो: product launch video, faceless explainer (चेहरा नसलेला माहितीपर video), talking-head video वर captions, music च्या beat वर चालणारा video, motion graphics, vertical social clip.

  • Install: npx skills add heygen-com/hyperframes (Claude Code मध्ये plugin म्हणूनही मिळतो). Node.js 22+ आणि FFmpeg लागतं.
  • Prompt: "/hyperframes — या 20 second गाण्याच्या beat वर माझ्या दुकानाचे हे 8 photos 9:16 मध्ये cut कर, शेवटी logo आणि पत्ता."
  • Prompt (explainer): "GST invoice म्हणजे काय यावर 30 second faceless explainer reel बनव, मोठे मराठी text cards, साधे icons."
  • कोणासाठी: Template-type reels, offer announcements, explainer content. Render laptop वर free होतो. Voiceover साठी free local option (Kokoro) आहे पण त्यात मराठी नाही; HeyGen avatar/voice साठी HeyGen account आणि credits लागतात.

3. Manim Skills

Manim हे 3Blue1Brown style गणित/diagram animation चं Python tool. Official Manim team चा skill नाही, पण community मधला adithya-s-k/manim_skill (MIT licence, GitHub वर 1,200+ stars) सगळ्यात लोकप्रिय आहे — Manim Community आणि ManimGL दोन्हीसाठी सूचना.

  • Install: npx skills add adithya-s-k/manim_skill. Python, FFmpeg आणि LaTeX लागतं — setup थोडा जड.
  • Prompt: "Manim ने 15 second animation बनव: 'SIP मध्ये दरमहा ₹2,000 टाकले तर 10 वर्षांत किती?' — graph हळूहळू वर जाताना दाखव."
  • कोणासाठी: Coaching classes, CA/financial advisors, tuition teachers — जिथे concept समजावायचा आहे.

4. video-use — Raw footage edit करणारा skill

browser-use/video-use (MIT licence) हा skill raw clips चा final video बनवतो: "अं… उं…" आणि रिकामे भाग कापतो, color grade करतो, subtitles burn करतो, गरज असेल तर HyperFrames/Remotion/Manim ने animation overlays जोडतो. Claude Code आणि Codex दोन्हीत चालतो.

  • Install: repo च्या README मधला setup prompt agent मध्ये paste करा — agent स्वतः install करतो. Transcription साठी ElevenLabs API key लागते (paid service, free tier मर्यादित).
  • Prompt: "या folder मधल्या 6 clips मधून 30 second reel बनव — मालक cake बद्दल बोलतोय, चुकलेले takes काढ, खाली मोठे captions."
  • कोणासाठी: Client ने phone वर shoot केलेले talking clips edit करणारे freelancers.

5. FFmpeg Skills — छोटी, रोजची कामं

FFmpeg हे video convert/cut/compress करणारं free tool. त्यासाठी अनेक community skills आहेत — उदा. OpenMontage project मधला ffmpeg skill (AGPL-3.0) किंवा gupsammy/claudest मधला convert-video (command चालवण्याआधी तुमची परवानगी मागतो). यांपैकी एकही official FFmpeg team चा नाही — install आधी SKILL.md वाचा.

  • Prompt: "हा 16:9 video 9:16 मध्ये crop कर, 30 second पर्यंत कापून, WhatsApp वर जाईल इतका compress कर."
  • कोणासाठी: सगळ्यांसाठी. खरं तर Claude Code ला skill शिवायही बरेच FFmpeg commands येतात; skill मुळे ते जास्त consistent होतं.

6. Thumbnail, poster आणि reel script साठी skills

  • canvas-design (Anthropic): anthropics/skills मध्ये. PNG/PDF poster किंवा static design बनवतो — reel cover, offer poster साठी. Prompt: "Diwali offer साठी 1080x1920 reel cover बनव, मध्ये मोठं '20% सूट'."
  • slack-gif-creator (Anthropic): नावात Slack आहे, पण छोटे animated GIF/sticker बनवायला उपयोगी.
  • social, video, image (marketingskills): coreyhaines31/marketingskills (MIT) मध्ये. social skill reels चे hooks, scripts आणि content calendar लिहितो; video skill AI video tools आणि Remotion/HyperFrames मधून योग्य मार्ग सुचवतो.

Script मराठीत नैसर्गिक हवी असेल तर prompt कसा लिहायचा हे मराठी Prompting Guide मध्ये आहे.

Practical Example: Pune bakery साठी 15 second Diwali offer reel

समजा कोथरूडमधल्या एका bakery ला Diwali faral box वर 15% सूट जाहीर करायची आहे. HyperFrames skill वापरून हे असं करता येईल:

  1. Setup (एकदाच): Laptop वर Node.js 22+ आणि FFmpeg install करा (हेही agent ला सांगून करून घेता येतं). Claude Code उघडा आणि लिहा: "heygen-com/hyperframes skills install कर."
  2. Material एका folder मध्ये: 4-5 product photos (faral box, करंजी, चकली), bakery चा logo, आणि एक मराठी font file (उदा. Google Fonts वरचा Mukta किंवा Noto Sans Devanagari).
  3. Prompt द्या:
/hyperframes — या folder मधल्या photos वापरून 15 second चा 9:16 (1080x1920) Instagram reel बनव.
Bakery: "गोडवा Bakery, कोथरूड, पुणे"
Scenes:
1) 0-3s: "दिवाळी फराळ Box" मोठ्या अक्षरात, दिव्यांचा soft glow
2) 3-10s: 4 photos एकामागून एक, प्रत्येकावर नाव (करंजी, चकली, लाडू, शंकरपाळी)
3) 10-13s: "15% सूट — 5 November पर्यंत"
4) 13-15s: logo + "Order: DM करा"
मराठी text साठी assets/fonts मधला Mukta font वापर. Voiceover नको, हलकं music चालेल.
आधी Studio preview दाखव, render नंतर.
  1. Preview तपासा: Agent preview उघडतो. मराठी अक्षरं नीट जुळली आहेत का (मात्रा, जोडाक्षरं तुटली नाहीत ना) ते नक्की बघा — हीच सगळ्यात common चूक असते.
  2. बदल साध्या भाषेत: "दुसरा scene थोडा हळू कर", "सूट चा text पिवळा कर" — agent बदल करतो.
  3. Render: "आता render कर" — MP4 folder मध्ये तयार. Phone वर पाठवून Instagram वर upload.
Freelancer साठी फायदा: एकदा हा reel जमला की पुढच्या client साठी फक्त photos, नाव आणि offer बदला. "हाच reel 'साई स्वीट्स, नाशिक' साठी, 10% सूट" — 10 मिनिटांत नवीन version. Voiceover हवा असेल तर मराठी voiceover वेगळा बनवून जोडा.

Skills, AI video models आणि editing tools एकत्र जोडून रोजचं content system कसं बनवायचं, ते Video Creation System या post मध्ये आहे.

बंद करताना

Skills मुळे AI agent "हुशार" होत नाही — त्याला फक्त तपासलेली पद्धत मिळते. पहिल्या आठवड्यात एकच skill निवडा (offer reels साठी HyperFrames किंवा Remotion), त्याने 5-6 reels बनवा, आणि काय जमतं, काय अडतं याच्या notes ठेवा. 20 skills install करून एकही नीट न वापरण्यापेक्षा एक skill पक्का शिकणं जास्त कामाचं.
