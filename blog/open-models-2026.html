2026 चे Open AI Models — Image, Video, Voice आणि Captions साठी

Tools & How-To · October 2026

Open-weight model म्हणजे ज्याचे weights (model ची "brain file") कंपनी Hugging Face वर public करते. कोणीही download करू शकतो, आणि fal.ai, Replicate सारख्या sites तो host करतात — त्यामुळे rate closed models पेक्षा कमी राहतो. पण "open" म्हणजे "client कामासाठी free" असं नाही. वापराच्या अटी प्रत्येक model च्या licence मध्ये असतात.

या post मध्ये चार कामांसाठी — image, video, Marathi voiceover आणि Marathi captions — प्रत्येकी 3-4 उपयोगी models. सगळी माहिती October 2026 ची, prices अंदाजे, $1 ≈ ₹95 धरून.

Client कामाआधी licence बघा. Apache 2.0 / MIT असेल तर commercial वापर साधारणपणे चालतो. बाकी custom licences मध्ये अटी असतात. तीन मुख्य सापळे:
  • FLUX.2 [dev]: weights "FLUX Non-Commercial" licence वर. स्वतःच्या GPU वर client कामासाठी चालवायला BFL चा paid licence लागतो. Commercial use allow करणाऱ्या hosted service वरून (उदा. Replicate, BFL API) वापरता येतो — त्या platform चे terms वाचा.
  • LTX-2.x (Lightricks): वार्षिक revenue $10 million पेक्षा जास्त असलेल्या कंपनीला paid licence लागतो. तुम्ही आणि local clients याच्या खूप खाली आहात.
  • Hunyuan (Tencent) आणि MiniMax H3: region ची अट. Hunyuan licence EU, UK, South Korea मध्ये लागू नाही; MiniMax H3 चा licence US, EU, UK, South Korea मध्ये नाही. India मध्ये चालतात, पण परदेशी client असेल तर टाळा.
हा legal advice नाही. मोठ्या client साठी model card वरचा licence स्वतः वाचा, आणि कोणत्या project मध्ये कोणता model वापरला याची नोंद ठेवा.

1. Image — posters, product shots

Prices fal.ai वरचे, per megapixel. 1024×1024 म्हणजे 1 MP; Instagram portrait (1080×1350) साधारण 1.5 MP, म्हणजे खर्च 1.5-2 पट.

  • Qwen-Image-Edit-2511 (Alibaba): product photo तसाच ठेवून background बदलणं, अनेक images एकत्र करणं. Freelancer साठी सगळ्यात उपयोगी. fal, Replicate · $0.03/MP ≈ ₹3 · Apache 2.0.
  • Qwen-Image-2512: poster backgrounds, realistic माणसं, English text बऱ्यापैकी. fal, Replicate · $0.02/MP ≈ ₹2 · Apache 2.0.
  • FLUX.2 [klein] 4B (Black Forest Labs): स्वस्त आणि fast drafts, thumbnails; editing सुद्धा. fal, Replicate · $0.005/MP ≈ ₹0.5 · Apache 2.0. (याच family चे 9B models non-commercial आहेत.)
  • Z-Image-Turbo (Alibaba Tongyi): स्वस्त realistic photos; 16GB GPU वर घरी चालतो. fal · $0.005/MP ≈ ₹0.5 · Apache 2.0.
Marathi text: कोणत्याही open image model च्या card वर Devanagari support चा उल्लेख नाही — मात्रा तुटतात, जोडाक्षरं चुकतात. Image text शिवाय बनवा ("leave empty space at the top for text") आणि Marathi text Canva मध्ये टाका. नवीन Qwen-Image-2.1 चा licence research-only आहे — client कामासाठी 2512 / Edit-2511 वापरा.

2. Video — Reels clips, b-roll

Prices fal.ai वरचे, एका 5-6 second clip साठी. जुने स्वस्त models बद्दल हा post बघा.

  • Wan 2.2 (Alibaba): character motion, स्वस्त drafts; vertical देतो, पण आवाज नाही. fal, Replicate · 5B ≈ $0.15 (₹14), A14B 720p ≈ $0.40 (₹38) · Apache 2.0 — सगळ्यात सोपा licence. (Wan 2.5/2.6 फक्त paid API वर, weights open नाहीत.)
  • LTX-2.3 / LTX-2.5 (Lightricks): video सोबत background आवाज, 9:16; 2.5 मध्ये multishot. fal, LTX Studio · LTX-2.3 Fast 1080p ≈ $0.25-0.35 (₹24-33); 2.5 चा rate जास्त, page वर बघा · LTX Community License ($10M अट).
  • HunyuanVideo 1.5 (Tencent): product photo → video, हलका model (8.3B). fal (16:9 आणि 9:16) · 480p ≈ $0.38 (₹36), reel साठी upscale लागेल · Hunyuan Community License (EU/UK/Korea नाही).
  • MiniMax H3: 15 second पर्यंत clip, stereo audio, dialogue. fal (2K) · ≈ $0.80-1.30 (₹76-124) — सगळ्यात महाग · MiniMax H3 Community License (US/EU/UK/Korea नाही; UI मध्ये model चं नाव दाखवावं लागतं).
Test: fal वर $10 चा credit टाका आणि एकाच prompt ने Wan 2.2 5B, LTX-2.3 Fast आणि HunyuanVideo 1.5 मधून एक-एक 9:16 clip बनवा. एकूण $1 च्या आत. Phone वर बघा आणि client च्या niche ला कोणता शोभतो ते ठरवा. Draft स्वस्त model वर, final clip चांगल्या model वर — असा नियम ठेवला तर बिल कमी राहतं. पूर्ण reel कशी जोडायची ते Video Creation System मध्ये आहे.

3. Voiceover (TTS) — Marathi बोलणारे

"Multilingual" लिहिलं म्हणजे Marathi बोलेल असं नाही — उदा. लोकप्रिय Kokoro-82M Hindi बोलतो, Marathi नाही. खालचे सगळे model card नुसार Marathi support करतात.

  • Indic Parler-TTS (AI4Bharat): English मध्ये आवाजाचं वर्णन लिहा ("A female speaker with a clear, cheerful voice"); Marathi voices Sanjay, Sunita (recommended) + 4. HF Space ai4bharat/indic-parler-tts · free · Apache 2.0.
  • IndicF5 (AI4Bharat): छोट्या reference clip वरून voice cloning. HF Space ai4bharat/IndicF5 · free · MIT, पण download साठी अटी accept कराव्या लागतात — फक्त permission असलेला आवाज clone करा.
  • Sarvam Bulbul v3 / v4 Flash: open-weight नाही, पण quality चांगली आणि try करायला सगळ्यात सोपं. sarvam.ai playground · v3 ₹3, Flash ₹1 प्रति 1,000 characters (30 second script ≈ 450 characters → ₹1.5 / ₹0.5) · paid API, Sarvam चे terms.
  • Indic-Speak (Bodhan AI): September 2026 चा नवीन model, English-Marathi mix साठी train केलेला (voices: Anagha, Chinmay). Gated, 3B, GPU लागतो · Indic Open Model License v1.0. अजून नवीन आहे — client कामाआधी स्वतः test करा.
Voice cloning आणि label: Client किंवा staff चा आवाज clone करायचा असेल तर त्या व्यक्तीची written permission घ्या. Celebrity, नेते यांचा आवाज कधीही नाही. AI voiceover असलेल्या reel ला Instagram वर AI label लावा. Meta चं mms-tts-mar CC-BY-NC आहे — client कामासाठी नाही.
उच्चार सुधारायची trick: आकडे आणि symbols शब्दांत लिहा — "₹199" ऐवजी "एकशे नव्याण्णव रुपये", "5%" ऐवजी "पाच टक्के". लांब script 2-3 तुकड्यांत बनवा.

4. Auto-Captions (STT) — Marathi

बहुतेक लोक reels आवाज बंद ठेवून बघतात. कोणताही tool वापरला तरी प्रत्येक शब्द हाताने तपासा.

  • OpenAI Whisper: Marathi support आहे, laptop वर चालतो; पण OpenAI स्वतः सांगतं की accuracy भाषेनुसार बदलते, आणि Marathi मध्ये चुका जास्त येतात. HF Spaces, Replicate · free (local) · MIT code / Apache 2.0 weights.
  • IndicConformer 600M (AI4Bharat): 22 Indian भाषांसाठी बनवलेला, Marathi सह. Setup technical (NeMo); community Spaces वर try करा · free · MIT (gated).
  • Sarvam Speech-to-Text: Indian भाषांसाठी hosted API, सगळ्यात कमी मेहनत. sarvam.ai · ₹0.49 प्रति minute (30 second reel ≈ 25 पैसे) · paid API.
  • CapCut auto-captions: सगळ्यात सोपं, phone वर. Marathi output कधी चांगलं, कधी नाही.
TTS वापरला असेल तर STT नको: Script तुमच्याकडे आधीच आहे — तोच text captions म्हणून टाका आणि timing जुळवा. Spelling चुका शून्य. Caption चा text लिहायला Marathi साठी Sarvam-30B (Apache 2.0, model card वर Marathi listed) हा open LLM test करून बघण्यासारखा आहे.

Prices बदलत राहतात — generate करण्याआधी model page वर एकदा बघा. एका client च्या महिन्याच्या 30 posts × 4 tries (120 images) चा खर्च drafts klein वर आणि final Qwen Edit वर केला तर साधारण ₹135 येतो.

GPU लागतो का?

  • नाही. वरचं सगळं fal, Replicate, HF Spaces किंवा Sarvam वर phone/budget laptop वरून चालतं. जेवढं वापरलं तेवढंच बिल.
  • घ्यायचाच असेल तर पहिला आकडा VRAM. Model GPU memory मध्ये बसला नाही तर चालत नाही किंवा खूप slow होतो. 16GB comfortable minimum; video models साठी 24GB आरामात.
  • NVIDIA (CUDA): सगळ्यात सोपं — नवीन models, ComfyUI nodes, tutorials आधी NVIDIA वर चालतात. AI साठी RTX 5060 Ti चा 16GB version घ्या, 8GB नाही.
  • AMD (ROCm): 16GB प्रति ₹ स्वस्त (RX 9060 XT / 9070 XT), पण software मध्ये अडचणी — काही video nodes CUDA-only, Windows वर support अजून अपूर्ण.
  • 2026 मध्ये memory तुटवड्यामुळे GPU prices वाढलेले आहेत. महिन्याचा cloud खर्च सातत्याने ₹3,000-4,000 च्या वर जाईपर्यंत GPU चा विचार करू नका.

बंद करताना

सुरुवातीसाठी एवढं पुरे: image editing ला Qwen-Image-Edit-2511, video drafts ला Wan 2.2, voiceover ला Indic Parler-TTS किंवा Sarvam, आणि Marathi text Canva मध्ये. सगळे Apache 2.0 किंवा paid API — licence चं टेन्शन कमी, खर्च महिन्याला काहीशे रुपये. नवीन model आला की 2-3 outputs वर test करा, licence वाचा, आणि मगच client कामात आणा. Code ने video बनवायचा पर्याय Remotion आणि Manim post मध्ये आहे.
