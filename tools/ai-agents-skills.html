AI Agents & Skills — Agent ला काम शिकवा, Reels बनवा

Chatbot पेक्षा एक पाऊल पुढे: laptop वरच्या folder मध्ये काम करणारा AI agent, त्याला skills शिकवणं, आणि एका प्रयत्नात 10 product reels.

हे पान hands-on आहे — step-by-step करून बघायचं. Skills म्हणजे काय आणि video साठी कोणते skills आहेत याची ओळख AI Agent Skills म्हणजे काय या blog post मध्ये आहे, आणि Remotion, HyperFrames, Manim ही tools कशी आहेत ते Code ने Video बनवा मध्ये. आधी ते वाचलेत तर हे पान लवकर समजेल.

Chatbot आणि Agent — फरक काय?

ChatGPT किंवा Claude च्या chat मध्ये तुम्ही प्रश्न विचारता, तो उत्तर लिहितो. File हवी असेल तर download करा, स्वतः उघडा, स्वतः जोडा. Agent हे काम स्वतः करतो: तुमच्या laptop वरच्या एका folder मधल्या files वाचतो, नवीन files बनवतो, commands चालवतो (उदा. video render करणं), आणि result तपासून परत सुधारतो. तुम्ही फक्त साध्या भाषेत सांगता आणि तो काय करतोय ते बघता.

Setup — Claude Desktop App (Windows / Mac)

Laptop लागतो — phone वर हे होत नाही. Anthropic च्या docs नुसार किमान: Windows 10 (version 1809+) किंवा macOS 13+, आणि 4 GB+ RAM. Budget laptop (8 GB RAM) वर चालतं, फक्त video render हळू होतो.

Step 1 — Claude Pro घ्या

  1. claude.ai वर account बनवा (Google account चालतो).
  2. Settings → Billing मध्ये Pro plan घ्या ($20/महिना). Claude Code Pro, Max, Team, Enterprise मध्येच येतो.

Step 2 — Desktop app install करा

  1. claude.com/download उघडा → तुमच्या system चा installer (Windows किंवा macOS) download करा.
  2. Installer चालवा. Mac वर Applications मधून, Windows वर Start menu मधून Claude उघडा आणि sign in करा.
  3. Sidebar मध्ये वर Code tab वर click करा. "Upgrade" दिसलं तर Pro अजून active झालेला नाही.

Step 3 — Project folder निवडा

  1. Laptop वर एक folder बनवा, उदा. Documents/reels-godwa-bakery. एका client साठी एक folder — हा नियम ठेवा.
  2. Code tab मध्ये prompt box खालच्या ओळीत environment मध्ये Local निवडा, मग Open folder… → तुमचा folder.
  3. Permission mode Manual ठेवा — agent प्रत्येक file बदल किंवा command आधी तुमची परवानगी मागेल. सुरुवातीला हेच सुरक्षित.

Step 4 — Video साठी Node.js आणि FFmpeg

Desktop app ला स्वतःला Node.js लागत नाही. पण Remotion/HyperFrames ने video बनवायला Node.js 22 किंवा पुढचं आणि FFmpeg लागतं. nodejs.org वरून LTS version install करा. FFmpeg agent लाच सांगा:

Promptमाझ्या laptop वर Node.js आणि FFmpeg install आहेत का ते तपास. नसतील तर install करायच्या steps सांग आणि प्रत्येक command चालवण्याआधी मला विचार. शेवटी दोन्हींचं version दाखव.
Terminal वाला मार्ग (optional): Terminal आवडत असेल तर Mac वर curl -fsSL https://claude.ai/install.sh | bash, Windows PowerShell मध्ये irm https://claude.ai/install.ps1 | iex — मग folder मध्ये claude टाइप करा. Windows वर Git for Windows install केलं तर agent जास्त commands नीट चालवू शकतो. Desktop app आणि terminal दोन्ही एकच Claude Code आहे.

Skills — Agent चं "कसं करायचं" पुस्तक

Skill म्हणजे एक folder ज्यात SKILL.md नावाची file असते: वर नाव आणि "हा skill कधी वापरायचा" याचं एका ओळीत वर्णन, खाली step-by-step सूचना. सोबत scripts, templates, fonts असू शकतात. Agent आधी फक्त नावं-वर्णनं वाचतो; तुमचं काम एखाद्या skill शी जुळलं की तेव्हाच पूर्ण skill उघडतो.

Skills install करण्याचे 3 मार्ग

  1. claude.ai (web/app): Settings → Capabilities मध्ये "Code execution and file creation" (नव्या layout मध्ये "Create and edit files") चालू करा. मग Customize → Skills → "+" → "+ Create skill" → "Upload a skill" → skill folder चा ZIP निवडा. ZIP मधल्या folder चं नाव skill च्या नावाशी जुळलं पाहिजे.
  2. Claude Code plugin marketplace: Code tab मध्ये किंवा terminal मध्ये: 
    /plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills
  3. skills CLI (skills.sh, Vercel): project folder मध्ये npx skills add owner/repo. एकच skill हवा असेल तर --skill नाव, सगळ्या projects साठी हवा असेल तर -g. यासाठी Node.js 22.20+ लागतो. हा command Claude Code, Codex, Cursor सगळ्यांसाठी चालतो.

Commands स्वतः टाइप करायची गरज नाही — agent ला सांगा: "npx skills add remotion-dev/skills चालवून Remotion skills install कर."

Hands-on: 10 Products, 10 Reels (Remotion)

समजा "गोडवा Bakery, कोथरूड" ला दिवाळीसाठी 10 products चे 8-second reels हवे आहेत. एकच design, फक्त photo-नाव-किंमत बदलते. हे Remotion चं खास काम आहे — Remotion च्या docs मध्ये dataset (JSON/CSV) मधून अनेक videos render करायची पद्धत दिली आहे. (HyperFrames ने पण करता येईल; पद्धत तीच.)

Step 1 — Material तयार ठेवा

  • photos/ folder: 10 product photos, साधी नावं — karanji.jpg, chakli.jpg. Phone ने उभे (portrait) काढलेले चांगले.
  • products.csv: Google Sheets मध्ये बनवा → File → Download → CSV. तीन columns:
name,price,photo
करंजी (250 ग्रॅम),180,karanji.jpg
चकली (250 ग्रॅम),160,chakli.jpg
बेसन लाडू (500 ग्रॅम),320,besan-ladu.jpg
  • logo.png — शक्यतो transparent background.

Step 2 — Skill install आणि पहिला prompt

Prompt 1 — Setupया folder मध्ये remotion-dev/skills install कर (npx skills add remotion-dev/skills). मग Remotion चा नवीन blank project बनव. प्रत्येक step आधी काय करणार ते मला एका ओळीत सांग.
Prompt 2 — TemplateRemotion मध्ये Instagram reel template बनव. Size 1080x1920, 30fps, 8 seconds. Data: products.csv (columns: name, price, photo). Photos photos/ folder मध्ये आहेत. प्रत्येक row साठी एक video: - 0-2s: product photo पूर्ण screen, हळूहळू zoom-in - 2-5s: खाली product नाव (मराठी) आणि "₹" सह किंमत slide-up - 5-8s: logo.png आणि "Order साठी DM करा · गोडवा Bakery, कोथरूड" Font: Noto Sans Devanagari (@remotion/google-fonts मधून load कर). Colors: #8B1E3F आणि #F5E6C8. आधी फक्त पहिल्या product चा Studio preview उघड. सगळे render आत्ता करू नकोस.

Step 3 — Preview तपासा आणि बदल सांगा

Agent Remotion Studio उघडतो (browser मध्ये preview). इथे घाई करू नका:

  • मराठी अक्षरं नीट आहेत का — "क्ष", "ज्ञ", "श्र", मात्रा तुटल्या नाहीत ना. Font Noto Sans Devanagari किंवा Mukta असला की सहसा बरोबर येतं.
  • Text phone च्या खालच्या भागात (Instagram चे buttons, caption) झाकला जात नाही ना.
  • बदल साध्या भाषेत: "किंमत मोठी आणि पिवळी कर", "zoom थोडा हळू", "logo वर उजवीकडे".

Step 4 — सगळे render करा

Prompt 3 — RenderPreview OK आहे. आता products.csv च्या सगळ्या rows चे MP4 out/ folder मध्ये render कर, एका वेळी एक. File चं नाव product च्या photo नावावरून ठेव (उदा. karanji.mp4). शेवटी किती files बनल्या आणि प्रत्येकीची size सांग.

Budget laptop वर 10 छोटे reels ना काही मिनिटं ते अर्धा तास लागू शकतो — render चालू असताना laptop चार्जिंगला लावा.

Step 5 — Proofread आणि deliver

  1. प्रत्येक MP4 phone वर पाठवून पूर्ण बघा — नाव, किंमत, spelling. एका चुकीच्या किंमतीमुळे client चा विश्वास जातो.
  2. चूक CSV मध्ये दुरुस्त करा आणि फक्त तो एक video परत render करायला सांगा.
  3. Trending audio Instagram app मधूनच लावा — post करताना.
Remotion licence: Individuals आणि 3 पर्यंत employees असलेल्या companies ना commercial use सकट free. 4 किंवा जास्त लोकांच्या agency ला company licence लागतं. HyperFrames Apache 2.0 आहे — अशी अट नाही. सविस्तर Code ने Video post मध्ये.

स्वतःचा Skill बनवा — Client Brand Kit

प्रत्येक वेळी "colours हे, font हा, tone असा" सांगण्यापेक्षा client चा एक छोटा skill बनवा. मग "गोडवा साठी Diwali caption लिही" एवढं म्हटलं तरी agent brand नियम पाळतो. Folder चं नाव आणि name सारखं ठेवा (lowercase, hyphen):

godwa-bakery-brand/
└── SKILL.md

---
name: godwa-bakery-brand
description: गोडवा Bakery (कोथरूड, पुणे) चे brand नियम. या client साठी reel, poster, caption किंवा hashtags बनवताना नेहमी वापर.
---

# गोडवा Bakery — Brand Kit

## Colours
- मुख्य: #8B1E3F (maroon)   - Background: #F5E6C8 (cream)   - Accent: #E8A33D

- English: Poppins

## Tone

- Emojis: जास्तीत जास्त 2 प्रति caption.
- "Best in Pune", "No.1" सारखे दावे करू नकोस.

## Hashtags (जास्तीत जास्त 5)
#गोडवाBakery #KothrudFood #PuneBakery #DiwaliFaral #पुणे

## Reel नियम
- Size 1080x1920, शेवटच्या 2 seconds मध्ये logo + "Order साठी DM करा".
- किंमत नेहमी "₹" सह, CSV मधूनच घे — स्वतः अंदाज लावू नकोस.
  • Claude Code: हा folder ~/.claude/skills/ मध्ये ठेवा (सगळ्या projects साठी) किंवा project folder मधल्या .claude/skills/ मध्ये (फक्त त्या client साठी). मग /godwa-bakery-brand टाइप करून बोलवता येतो.
  • claude.ai: folder ZIP करा आणि Customize → Skills मध्ये upload करा.
  • लिहायचा कंटाळा? agent ला सांगा: "या client साठी brand kit skill बनव — मी प्रश्नांची उत्तरं देतो." Anthropic चा skill-creator skill हेच काम करतो.

खर्च आणि Safety

  • खर्च: Skills बहुतेक free. Agent चा subscription — Claude Pro $20/महिना किंवा ChatGPT Plus साधारण $20/महिना. Pro मध्ये usage limit असतो; मोठे render-दुरुस्त्या एका दिवसात केल्या तर limit संपू शकतो — काही तासांनी परत मिळतो. API key वापरून चालवलं तर प्रत्येक काम वेगळं billed होतं — सुरुवातीला subscription च बरा.
  • Paid API keys: काही skills (video-use, HeyGen avatar) ElevenLabs/HeyGen keys मागतात. Key म्हणजे पैसे — कोणाला share करू नका.
  • Client service ची किंमत: हा subscription तुमचा business खर्च आहे — "10 product reels" package ची किंमत ठरवताना तो धरा.
Skill = तुमच्या laptop वर चालणारा code:
  • फक्त trusted sources कडूनच skills — official repos (Anthropic, Remotion, HeyGen) ला प्राधान्य. GitHub stars जास्त म्हणजे safe नाही.
  • Install आधी SKILL.md उघडून वाचा. "हा URL ला data पाठव", "key इथे paste कर" असं विचित्र दिसलं तर थांबा. Agent ला विचारा: "हा skill काय करतो ते मराठीत सांग, काही धोकादायक आहे का?"
  • Client चे Instagram/Facebook passwords, OTP, bank details agent ला किंवा कोणत्याही file मध्ये कधीही देऊ नका.
  • Agent ला फक्त त्या client चा folder द्या — पूर्ण Documents किंवा Desktop नाही. Permission mode Manual ठेवा.
  • Backup: Client चे original photos आणि CSV Google Drive वर वेगळे ठेवा. Agent चुकून file overwrite करू शकतो.

सराव — 3 Products, 3 Reels

तुमच्या ओळखीचं एखादं दुकान (किंवा स्वतःचं काल्पनिक) घ्या:

  1. Claude desktop app install करा, Code tab मध्ये नवीन folder उघडा.
  2. 3 products चे phone photos आणि products.csv (name, price, photo) बनवा.
  3. वरचा brand kit SKILL.md त्या दुकानासाठी बदलून install करा.
  4. Prompt 1, 2, 3 वापरून 3 reels render करा. Preview मध्ये कमीत कमी 2 बदल सांगा.
  5. Font test: एका reel मध्ये "क्षमा, ज्ञान, श्रीगणेश, दिवाळीच्या शुभेच्छा" टाकून तपासा.
  6. लिहून ठेवा: setup ला किती वेळ लागला, 3 reels ला किती. Edits/CapCut मध्ये हेच किती वेळात झालं असतं?

Checklist: ☐ मराठी जोडाक्षरं बरोबर ☐ किंमती CSV शी जुळतात ☐ Text Instagram buttons खाली झाकला नाही ☐ Originals चा backup ☐ कोणताही password agent ला दिला नाही

Skills, AI video models आणि editing एकत्र करून रोजचं content system कसं बनवायचं ते Video Creation System post मध्ये आहे.
